# 架构与数据流

浏览器文件选择后逐份上传，服务端生成随机 ID 并记录名称、大小和摘要。上传副本只读，转换配置由 Zod 校验，并在创建任务时形成快照。

任务调度根据 CPU 和可用内存限制工作线程。每个文件独立分析，错误作为单文件结果返回。成功结果生成后，单文件由下载接口发送，多文件由 Archiver 输出 ZIP。

## 内容约束

`window.files` 和其同段预加载数据作为受保护脚本。模型数据不进入字符串全局替换。转换前后比较该脚本的 SHA-256，不一致时不输出文件。

UI 脚本使用 Babel 读取字符串的真实值，支持中文转义。删除 React 创建调用，清理其无引用声明与专用坐标事件。SVG 文字先解码，再按完整 text 显示内容识别，处理跨 tspan 分段的提示。

CSS 的连续 push 片段组成完整样式。资源引用以占位符进入 PostCSS，删除专用选择器后按保留片段生成表达式，共享选择器和声明继续保留。无引用图像表达式交由 Terser 清理。

LOGO 使用静态 div 和文本或 img，不继承原元素的点击、鼠标与编辑器导航处理。网站标题通过独立配置写入 title，不与 LOGO 内容混用。

侧栏使用原父组件的通知接口更新预览空间。按钮和尺寸调整区域分别设置热区。Pointer Capture 保证手指离开调整区域后，拖动仍由原目标处理。取消和失去捕获时释放拖动状态。

## 接口

| 路径 | 行为 |
| --- | --- |
| `GET /api/health` | 项目与运行时健康信息 |
| `GET /api/capabilities` | 有效上传限制和预览源 |
| `POST /api/uploads` | 接收一份 HTML 并返回 ID |
| `POST /api/logo-assets` | 规范化静态媒体并返回 assetId |
| `POST /api/conversions` | 创建配置固定的转换任务 |
| `GET /api/conversions/:id` | 查询状态和单文件报告 |
| `GET /api/conversions/:id/download` | 下载 HTML 或 ZIP |
| `DELETE /api/conversions/:id` | 取消转换 |

下载文件无需服务器参与运行。在线预览使用另一 HTTPS 端口，COOP 和 COEP 提供跨源隔离。工具接口不向预览源开放跨源写入。

Rust 渲染线程池使用设备逻辑核心数，上限为 4。共享内存不可用时走单线程 WASM。页面默认渲染方式保留原引擎的能力选择，简图支持 WebGPU。活动 API 请求延续会话有效期，输入和结果的独立保留期限由存储层控制。
