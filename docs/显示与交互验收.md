# 显示、滚动、菜单与表格验收

项目为嘉立创文件转换 JLCFConv，作者 NianBroken。项目地址为 https://github.com/NianBroken/JLCFConv。

## 实施顺序与复现证据

1. 使用 `test-results/planning-display-20261109` 中已执行的 17 个页面状态、基线断言与截图核对原有问题，保留原始样本。
2. 将浏览器量测整理为 `tests/display-regression.ts`，覆盖桌面、手机、左右侧栏、底栏、收起、最小尺寸、横竖屏、滑块拖动和表头对齐。
3. 将工具与输出 HTML 接入 OverlayScrollbars 2.17.0，统一原生视口接管、主题、动态发现和资源释放。
4. 处理侧栏尺寸约束、SVG 侧栏图标、字段对应的表头列宽、手机占位标题、显示模式排版、缺失值显示与提示资源。
5. 按滚动条细度要求，将可见宽度统一为 4 CSS 像素，保持鼠标与触摸操作入口，并通过真实拖动核对内容移动。
6. 对菜单间距、表格空白与长内容要求执行独立基线，保存 `test-results/layout-baseline` 的截图和量测。桌面可用宽度 1240 像素时表格仅为 961 像素，手机宽屏可用宽度 1640 像素时表格仅为 856 像素。长内容的计算样式为允许换行。
7. 使用实际容器宽度进行等量分配，统一单行省略规则，取消手机菜单的固定高度和分散排列。
8. 构建生产产物，通过 Windows 后台任务重启 HTTPS 服务，使用真实样本执行上传、转换、自动下载、预览与离线打开。

## 当前行为

| 范围       | 行为                                                                                          |
| ---------- | --------------------------------------------------------------------------------------------- |
| 滚动条     | 工具与输出 HTML 共用主题，横纵滑块均为 4 像素，悬停和拖动不增粗，轨道透明且不占布局空间       |
| 侧栏按钮   | SVG 箭头、轻边框与浅阴影，可见按钮轮廓紧凑，操作热区至少 44 × 44 像素                         |
| 侧栏滚动   | 视口跟随实际面板宽高，180 像素最小左栏与 120 像素底栏保留可见轨道及滚动能力                   |
| 手机标题   | 移除冗余 PCB 名称区域，保留静态自定义 LOGO                                                    |
| 表头与数据 | 同一字段列映射决定顺序与基础宽度，聚合和非聚合表分别维护字段身份                              |
| 宽度分配   | 内容基础宽度小于可用宽度时，将剩余宽度平均分到可见列；空间不足时保留基础宽度并提供横向滚动    |
| 内容截断   | 长位号、型号、封装与参数文字保持单行，溢出末尾显示省略号；详情操作保持独立可用                |
| 手机菜单   | 相邻选项间距为 4 像素，选项高度至少 24 像素，内容内边距为 12 像素；菜单位于头部下方并保留间隔 |
| LOGO       | 文字自然换行，图片按实际可用空间等比收缩，菜单入口保持可见                                    |
| 提示       | 普通、转义、模板和 SVG 资源中的指定提示使用中山市勤奋光电科技有限公司                         |
| 参数缺失   | 真实缺失参数显示未提供，已有参数值与模型数据保持原样                                          |
| BOM 高亮   | 模型未就绪或当前器件没有真实渲染模型时，不发送不存在模型的高亮请求                            |

## 配置边界

滚动条始终参与工具与输出页面。表格、菜单、异常标题、参数显示、LOGO 对齐和公司提示属于网页优化。侧栏按钮外观和滚动区域尺寸属于交互优化。原有 API 与配置结构保持兼容。

图片与长文字 LOGO、标题特殊字符和两个开关的四种组合通过 `tests/configurations.ts` 实际提交转换，输出保存在 `test-results/configuration-*.html`。

## 实测尺寸与运行

手机宽屏表格宽度与可用宽度均为 1640 像素，7 列各获得 112 像素额外宽度。桌面宽屏表格宽度与可用宽度均为 1240 像素，8 列各获得 34.875 像素额外宽度。表头与数据使用一致边界。

浏览器完整流程使用有效证书，没有忽略 TLS 校验。Node 接口测试通过 `NODE_EXTRA_CA_CERTS` 信任项目根证书。正常运算的原厂诊断按项目既定口径保留，没有覆盖 console 或隐藏真实错误。

服务通过设备级 Node.js LTS 和 Windows 计划任务持续运行。真实 URL、端口与进程信息在 `.runtime/service.json`，计划任务和证书核验在 `test-results/service-report.json`。当前局域网工具地址为 https://192.168.168.35:3443/。

离线文件内嵌样式、脚本和第三方许可，不依赖 CDN。既有下载文件不会随服务更新，界面规则通过重新转换原始 HTML 写入新文件。

实现依据为 OverlayScrollbars 官方文档、MDN text-overflow 文档和 CSSOM 规范：

- https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/text-overflow
- https://www.w3.org/TR/cssom-1/
